# TinyC `.pvs`-Editor

Bearbeitet die `.pvs` eines TinyC-Slots direkt — die Datei, in der das laufende
Programm seine `persist`-Variablen hält (`/sml_chart.tcb` → `/sml_chart.pvs`).
[`tinyc_chart_editor.html`](tinyc_chart_editor.html) im Browser öffnen — kein
Server, es wird nichts hochgeladen.

**📖 Anleitung:
[ottelo9.github.io/tasmota-sml-script/pvs_editor](https://ottelo9.github.io/tasmota-sml-script/pvs_editor/)**

Dorthin zeigt auch der ℹ️-Knopf oben rechts im Werkzeug. Die Seite gibt es auf
Deutsch und Englisch.

Wer von einem Tasmota-Scripter-Script umzieht, nimmt
[`script_charts_to_tinyc_pvs.html`](script_charts_to_tinyc_pvs.html).
