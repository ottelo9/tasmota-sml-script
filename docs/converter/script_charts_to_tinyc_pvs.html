Scripter-Diagramme → TinyCi

Übernimmt die Balkendiagramme (Tages- und Monatsverbrauch, Einspeisung) aus den Scripter-Scripten in die TinyC-Programme. In vier Schritten, ohne Vorkenntnisse. Wer schon auf TinyC ist und nur seine Diagramme ansehen will, nimmt tinyc_chart_editor.html.
Die .bin ist nur für den einmaligen Import zum TinyC Programm gedacht. Die Daten liegen in der .pvs Datei des Slots (z.B. /sml_chart.tcb → /sml_chart.pvs). Beim Start liest das Programm /sml_chart.bin einmal, schreibt sie in die .pvs und löscht sie danach — die Datei ist weg, das ist die Markierung „schon importiert".
1. Diagrammdaten vom alten Gerät holen noch nichts geladen
Empfohlen: IP des alten Geräts eintragen. Dann werden die Links zum Holen der Daten (z.B. data.csv) automatisch hier auf der Seite generiert. Dafür muss Configuration › Other › HTTP API enable aktiviert sein. Die data.csv kann aber auch manuell vom alten Gerät geladen werden via Tools › Manage File System (nicht beim ESP8266 1M verfügbar, da gehts nur via Console oder HTTP API).
a) Import via HTTP/IP vom alten Gerät — Link anklicken, im neuen Browser-Tab alles auf der Seite markieren und kopieren (inkl. den { }) und hier einfügen. Der 24-h-Verlauf lässt sich mit dieser Methode allerdings nicht importieren (zu viel Daten).

2. Basiswerte auslesen und eintragen
Die Basiswerte (Zählerstände z.B. am Anfang des Monats/Jahres …) werden zur Berechnung der Verbräuche benötigt und stehen nicht in der data.csv (sie sind nur in den p:-Variablen des Scriptes). Ohne den Import dieser Basiswerte werden alle Verbräuche auf dem neuen Gerät falsch angezeigt (z. B. negativ oder der ganze Zählerstand). Erst durch ein Reset (⚙️ Optionen › 🔢 Reset) können die Werte auf dem neuen Gerät genullt werden. Im TinyC Programm werden diese Basiswerte fortan in der tc_options.cfg gespeichert (siehe auch Import Schritt 3). Bleiben die Felder leer, musst du auf dem Gerät, wie gesagt, einmal Tages/Monats/Jahres-Verbrauchswerte zurücksetzen.
Auf den Link klicken (IP in Schritt 1), im neuen Browser-Tab alles auf der Seite markieren und kopieren (inkl. den { }) und hier einfügen — bei den PV-Scripten für beide Links nacheinander.
Basiswerte in vorhandene tc_options.cfg integrieren (optional):
Falls bereits ein TinyC-Programm auf dem neuen Gerät läuft und ihr in den [⚙️ SML] Optionen was eingestellt habt (z.B. Stromzähler gewählt), dann könnt ihr hier die Optionsdatei (tc_options.cfg) herunterladen und die Basiswerte in diese Datei integrieren lassen. Habt ihr noch nix gemacht, dann überspringt den Schritt. (Hinweis: Tasmota eigene Einstellungen wie z.B. WLAN werden woanders gespeichert!)
3. Import-Dateien herunterladen
Die heruntergeladenen Import-Dateien (.bin/.cfg) können nun auf dem neuen Gerät (das mit TinyC) via Manage File System hochgeladen werden (vorher das TinyC Programm stoppen).
Import Anleitung:
  1. TC-Programm (Slot) stoppen (falls was läuft): Tools › TinyC Console › das rote ■
  2. Dateien hochladen: Tools › Manage File system › Upload (alle Dateien einzeln hintereinander hochladen).
  3. TC-Programm (Slot) starten: Tools › TinyC Console › das grüne ▶
Läuft das TinyC-Programm beim Hochladen noch, werden alle importierten Einstellungen nach einem Neustart wieder überschrieben. Das Programm importiert die .bin Datei(en) einmal und löscht sie danach — ab dann ist die .pvs der Laufzeit-Speicher. In der Console kann geprüft werden, ob der Import geklappt hat (sml_chart: .bin carried baselines und sml_chart: imported .bin into .pvs, /sml_chart.bin deleted).
