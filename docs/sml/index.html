OverviewÜberblick

An ESP32 with a reading head sits on your electricity meter and reads it over SML. Every program of this family shares the same meter setup; they differ in what they add on top: charts, a meter emulator for a PV battery, a Modbus slave.

Requirements: ESP32 (no ESP8266), Tasmota with TinyC and USE_SML, and a reading head (examples on my blog).

Everything is set up on the web page, no code editing. Language, meter, pins and options are stored on the device.

Buttons in Tasmota's main menu. A running program adds its own entries:

⚙️ SMLAll settings. Programs with a battery emulator show ⚙️ SML /🔋 instead.
☁️ MarstekOnly in the CT002 programs: account and CT registration.
💻 TinyCTasmota's TinyC page — slots, upload, editor.

The charts have a page of their own, reached by the 📈 link under the readings on the main page. They are no longer drawn into the main page, which used to make it slow.

Ein ESP32 mit Lesekopf sitzt am Stromzähler und liest ihn über SML aus. Alle Programme dieser Familie teilen sich die gleiche Zählereinrichtung; sie unterscheiden sich nur in dem, was oben drauf kommt: Diagramme, ein Zähler-Emulator für eine PV-Batterie, ein Modbus-Slave.

Voraussetzungen: ESP32 (kein ESP8266), Tasmota mit TinyC und USE_SML und ein Lesekopf (Beispiele auf meinem Blog).

Alles wird auf der Weboberfläche eingestellt, nichts im Code. Sprache, Zähler, Pins und Optionen liegen auf dem Gerät.

The current smoothed value is shown in this section on the settings page. It used to sit on the main page as Power (smoothed) and moved here, next to the switch that publishes it.

The publishes carry log level 3: the console stays quiet at weblog 2 and shows them from weblog 3, without recompiling. A failed publish is logged once with its return code — -2 means MQTT is switched off on the device (SetOption3).

Buttons in Tasmotas Hauptmenü. Ein laufendes Programm ergänzt eigene Einträge:

⚙️ SMLAlle Einstellungen. Programme mit Akku-Emulator zeigen stattdessen ⚙️ SML /🔋.
☁️ MarstekNur in den CT002-Programmen: Konto und CT-Registrierung.
💻 TinyCTasmotas TinyC-Seite — Slots, Upload, Editor.

Die Diagramme haben eine eigene Seite, erreichbar über das 📈 unter den Messwerten auf der Hauptseite. Sie werden nicht mehr in die Hauptseite gezeichnet, was diese früher langsam gemacht hat.

Install

  1. Console: TinyCIde, then open http://<ip>/tc.
  2. Load the .tc file, Compile, Upload into slot 0.
  3. Tick autoexec, or start it with TinyCRun /<name>.tcb.

Slot 0 only for the emulator variants: their HTTP endpoints are webOn handlers, and Tasmota dispatches those to slot 0.

Each program keeps its own settings file. Switching programs means setting the meter up again.

Installation

Jedes Programm hat seine eigene Einstellungsdatei. Beim Wechsel muss der Zähler neu eingerichtet werden.

Meter settingsZähler-Einstellungen

Descriptor

The descriptor tells the SML driver how to read your meter: baud rate, protocol and which OBIS codes go into which value. It lives in /sml_meter.def.

Meter activeSwitches the SML driver on and off (Rule1). Off means no readings at all.
From repoPulldown with ready-made descriptors from my repository. Picking one downloads it and restarts the driver.
Edit descriptorOpens the file editor for hand-tuning. Your meter not in the list? Start from the closest one.

The first three values are fixed by convention and everything else builds on them: 1 power [W], 2 import [kWh], 3 export [kWh].

Der Descriptor sagt dem SML-Treiber, wie dein Zähler zu lesen ist: Baudrate, Protokoll und welcher OBIS-Code in welchen Wert geht. Er liegt in /sml_meter.def.

Zähler aktivSchaltet den SML-Treiber ein und aus (Rule1). Aus heißt: gar keine Messwerte.
Aus RepoAuswahlliste mit fertigen Descriptoren aus meinem Repository. Eine Auswahl lädt ihn herunter und startet den Treiber neu.
Descriptor bearbeitenÖffnet den Dateieditor zum Anpassen. Zähler nicht in der Liste? Mit dem ähnlichsten anfangen.

Die ersten drei Werte sind per Konvention festgelegt, alles andere baut darauf auf: 1 Leistung [W], 2 Bezug [kWh], 3 Einspeisung [kWh].

Pins

RX is the pin the reading head's data line goes to. TX is only needed for meters that have to be woken up or that expect a request.

RX 3 · TX 1Hichi, Stromleser, LesekopfV32, Wattwächter
RX 5 · TX 4bitShake

The pulldown only offers pins Tasmota has left free. A pin already assigned in the module configuration will not show up.

Changing a pin rewrites the descriptor and restarts the driver — no reboot needed.

RX ist der Pin, an dem die Datenleitung des Lesekopfs hängt. TX braucht man nur bei Zählern, die geweckt werden müssen oder eine Anforderung erwarten.

RX 3 · TX 1Hichi, Stromleser, LesekopfV32, Wattwächter
RX 5 · TX 4bitShake

Die Auswahlliste zeigt nur Pins, die Tasmota frei gelassen hat. Ein in der Modulkonfiguration belegter Pin taucht nicht auf.

Eine Pin-Änderung schreibt den Descriptor neu und startet den Treiber neu — ohne Neustart des Geräts.

Filter

A median filter over the incoming power values. It throws away single outliers — the spikes that make a chart unreadable and an emulator regulate against nothing.

Leave it on unless you need the raw value. It costs a little response time, which matters only for battery regulation.

Ein Median-Filter über die eingehenden Leistungswerte. Er wirft einzelne Ausreißer weg — die Spitzen, die ein Diagramm unlesbar machen und einen Emulator gegen nichts regeln lassen.

Ruhig anlassen, außer du brauchst den Rohwert. Er kostet etwas Reaktionszeit, was nur bei der Akkuregelung eine Rolle spielt.

DisplayAnzeige

The SML driver can print its own rows on the main page, with the meter name in front of every value. The script prints the same values itself, in your language and without the prefix.

OFF (default)Only the script's rows. Tidier.
ONDriver rows as well — useful while setting up a descriptor, because you see every value it produces, not just the first three.

The MQTT telemetry (SENSOR) always contains the driver's values, whatever this is set to. Home Assistant is unaffected.

Der SML-Treiber kann eigene Zeilen auf der Hauptseite ausgeben, mit dem Zählernamen vor jedem Wert. Das Script gibt dieselben Werte selbst aus — in deiner Sprache und ohne Präfix.

AUS (Standard)Nur die Zeilen des Scripts. Aufgeräumter.
EINZusätzlich die Treiberzeilen — praktisch beim Einrichten eines Descriptors, weil du jeden erzeugten Wert siehst, nicht nur die ersten drei.

Die MQTT-Telemetrie (SENSOR) enthält die Treiberwerte immer, unabhängig von dieser Einstellung. Home Assistant merkt davon nichts.

PV

Only in the chart variants. OFF shows consumption alone, ON adds feed-in: day, month and year rows, a daily production chart and a month chart with both directions.

Switch it on if your meter has a feed-in register (1.8.0 and 2.8.0). Without solar the extra charts stay at zero.

Nur in den Diagramm-Varianten. AUS zeigt nur den Verbrauch, EIN nimmt die Einspeisung dazu: Tages-, Monats- und Jahreszeile, ein Tagesertragsdiagramm und ein Monatsdiagramm mit beiden Richtungen.

Einschalten, wenn dein Zähler ein Einspeiseregister hat (1.8.0 und 2.8.0). Ohne PV bleiben die zusätzlichen Diagramme auf null.

Chart dataDiagrammdaten

Init meter valuesSets day, month and year baselines to the current meter reading. Do this once after installing, otherwise the first day shows the whole meter total.
Reset bar chartsClears the day and month columns. The counters keep running.
Save chart dataWrites the chart data to flash now. It is also saved automatically, this is for before a deliberate reboot.

The data lives in /sml_chart.bin and is exported to /sml_chart.csv. Both survive a firmware update, both are lost when the file system is erased.

Charts need the clock. Before the device has NTP time (2020) nothing is recorded.

Zählerwerte initialisierenSetzt die Tages-, Monats- und Jahresbasis auf den aktuellen Zählerstand. Einmal nach der Installation machen, sonst zeigt der erste Tag den kompletten Zählerstand.
Balkendiagramme zurücksetzenLöscht die Tages- und Monatsspalten. Die Zähler laufen weiter.
Diagrammdaten speichernSchreibt die Diagrammdaten sofort in den Flash. Das passiert auch automatisch; der Knopf ist für den bewussten Neustart davor.

Die Daten liegen in /sml_chart.bin und werden nach /sml_chart.csv exportiert. Beide überstehen ein Firmware-Update, beide sind weg, wenn das Dateisystem gelöscht wird.

Diagramme brauchen die Uhr. Bevor das Gerät NTP-Zeit hat (2020), wird nichts aufgezeichnet.

TelemetryTelemetrie

Default OFF. Switched ON, the script publishes a heavily smoothed power value every 5 s and serves it over HTTP as well.

MQTT

stat/<topic>/script/power2Smoothed power [W]. Exponential average, 10 % new value per step — slow on purpose.
stat/<topic>/script/cpwrEmulator variants only: the value handed to the battery, after offset and shaping.

HTTP /pwr

{"power2":-217,"cpwr":-180,"power":-440,"in":26714.950,"out":659.775}

For a second battery that polls over HTTP instead of listening for a meter — opendtu-onbattery's dynamic power limiter, for example. With telemetry off the endpoint answers {"enabled":0}.

Why smoothed: a battery that follows every spike swings. power is the raw value, power2 the calm one.

Standard AUS. Auf EIN veröffentlicht das Script alle 5 s einen stark gemittelten Leistungswert und liefert ihn zusätzlich über HTTP.

MQTT

stat/<topic>/script/power2Gemittelte Leistung [W]. Exponentieller Mittelwert, 10 % neuer Wert pro Schritt — absichtlich träge.
stat/<topic>/script/cpwrNur Emulator-Varianten: der Wert, den der Akku bekommt, nach Offset und Regleroptimierung.

HTTP /pwr

{"power2":-217,"cpwr":-180,"power":-440,"in":26714.950,"out":659.775}

Für einen zweiten Akku, der über HTTP pollt statt auf einen Zähler zu horchen — zum Beispiel der Dynamic Power Limiter von opendtu-onbattery. Bei ausgeschalteter Telemetrie antwortet der Endpunkt mit {"enabled":0}.

Warum gemittelt: ein Akku, der jeder Spitze folgt, schwingt. power ist der Rohwert, power2 der ruhige.

Der aktuelle gefilterte Wert steht in diesem Abschnitt auf der Einstellungsseite. Früher stand er als Leistung (gefiltert) auf der Hauptseite und ist hierher gewandert, neben den Schalter, der ihn versendet.

Die Publishes tragen Log-Stufe 3: bei weblog 2 bleibt die Konsole ruhig, ab weblog 3 werden sie sichtbar, ohne neu zu übersetzen. Ein fehlgeschlagener Publish wird einmal mit Rückgabewert protokolliert — -2 heißt, MQTT ist auf dem Gerät abgeschaltet (SetOption3).

Modbus-TCP

Default OFF. Switched ON, the device is a Modbus-TCP slave (server) and any client can read the meter.

Address4x referenceValueUnit
040001PowerW
240003ImportkWh
440005ExportkWh

Two numbering conventions exist for the same registers, which is the usual source of an illegal data address. The left column is the address that goes on the wire; the right one is the 4x notation that counts from 1.

Testing with Modbus Poll

Modbus Poll counts from 0 unless PLC addresses (base 1) is ticked — then it shows the 4x references instead.

Function03 Read Holding Registers
Address0 (or 40001 with PLC addresses)
Quantity2 for one value, 6 for all three

The reply arrives as single 16-bit registers. To see a real number, select the two registers that belong to one value, then Format → 32-bit Float Big-Endian.

Two registers per value, 32-bit IEEE-754 float, big-endian. Holding registers, FC03 only. Reads must start on a value boundary and cover whole values.

Port 502 is standard. Change it if something else on the device already uses it. The change takes effect within a second, no reboot.

Anything outside the map is answered properly: a wrong function code gives exception 01, a bad address exception 02, and an odd or oversized quantity exception 03. A quantity of 1 is therefore refused — half a float is not a value.

Standard AUS. Auf EIN ist das Gerät ein Modbus-TCP-Slave (Server), und jeder Client kann den Zähler lesen.

Adresse4x-BezeichnungWertEinheit
040001LeistungW
240003BezugkWh
440005EinspeisungkWh

Für dieselben Register gibt es zwei Zählweisen, und daher kommt fast jedes illegal data address. Links steht die Adresse, die auf die Leitung geht, rechts die 4x-Schreibweise, die ab 1 zählt.

Testen mit Modbus Poll

Modbus Poll zählt ab 0, solange PLC addresses (base 1) nicht angehakt ist — mit Haken zeigt es die 4x-Bezeichnungen.

Function03 Read Holding Registers
Address0 (mit PLC addresses 40001)
Quantity2 für einen Wert, 6 für alle drei

Die Antwort kommt als einzelne 16-Bit-Register. Damit eine echte Zahl erscheint, die zwei zusammengehörenden Register markieren und dann Format → 32-Bit Float Big-Endian wählen.

Zwei Register je Wert, 32-Bit-IEEE-754-Float, big-endian. Holding-Register, nur FC03. Ein Lesezugriff muss auf einer Wertgrenze beginnen und ganze Werte umfassen.

Port 502 ist Standard. Nur ändern, wenn ihn auf dem Gerät schon etwas anderes benutzt. Die Änderung greift innerhalb einer Sekunde, ohne Neustart.

Alles außerhalb der Tabelle wird sauber beantwortet: falscher Funktionscode gibt Exception 01, falsche Adresse Exception 02, eine ungerade oder zu große Anzahl Exception 03. Quantity 1 wird deshalb abgelehnt — ein halber Float ist kein Wert.

TroubleshootingFehlersuche

All values 0Check Meter active, then the pins, then the descriptor. Show driver rows on tells you whether the driver is producing anything at all.
Power has the wrong signImport and export are swapped in the descriptor. Feed-in must be negative.
Values jumpSwitch the filter on. If it stays wild, the reading head is sitting badly.
Charts stay emptyNo NTP time yet, or the baselines were never initialised. See chart data.
Settings lost after rebootSettings are written when they change and at program stop. A power cut in between can cost the last change.
Modbus does not answerCheck the port, and whether the network was up when the program started. weblog 4 shows the bind.
Alle Werte 0Erst Zähler aktiv prüfen, dann die Pins, dann den Descriptor. Treiberzeilen zeigen an verrät, ob der Treiber überhaupt etwas liefert.
Leistung mit falschem VorzeichenBezug und Einspeisung sind im Descriptor vertauscht. Einspeisung muss negativ sein.
Werte springenFilter einschalten. Bleibt es unruhig, sitzt der Lesekopf schlecht.
Diagramme bleiben leerNoch keine NTP-Zeit, oder die Basiswerte wurden nie initialisiert. Siehe Diagrammdaten.
Einstellungen nach Neustart wegEinstellungen werden bei Änderung und beim Programmende geschrieben. Ein Stromausfall dazwischen kann die letzte Änderung kosten.
Modbus antwortet nichtPort prüfen und ob das Netzwerk beim Programmstart schon stand. weblog 4 zeigt das Binden.
