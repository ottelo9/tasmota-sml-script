OverviewÜberblick

Do you have a newer electricity meter with an optical interface (SML) at home, and would you like to see its values, such as power and consumption (and feed-in), as charts on a nice web page, and record them? Then you are in the right place. With a suitable meter reading head that has a small processor (ESP) built in, and the right software, you can do all of this for little money. You are not tied to any cloud or manufacturer. If you know your way around, you are welcome to adapt the software as you like. But for most people my software already offers every option they need.

On my two GitHub pages (called repositories) I offer ready-made Tasmota firmware images and the matching programs (or scripts) for the ESP32 (and ESP8266). If you have already bought a Tasmota reading head, it contains an ESP32 or an ESP8266 (ESP01s), and a Tasmota version is already installed on it. To run my programs or scripts, however, you must put my firmware on the reading head. You can do this over Wi-Fi (OTA) or with a USB cable on your PC. I recommend OTA.

This page describes my programs for the reading head. They are written in the programming language TinyC, which is why I call them TinyC programs everywhere here. I made them only recently; before, I did everything with Tasmota scripts. TinyC can do much more, so this page only covers the TinyC programs. Basically, I turned all my separate scripts into a few TinyC programs. Before, if you wanted Modbus, you had to take a separate script. Now it is simply an option.

The TinyC programs need an ESP32. For the ESP8266 there are only the scripts. Examples of suitable reading heads are on my blog.

Once my image runs on your reading head, you choose and load one of my programs directly in Tasmota on the ESP / reading head. You do not have to upload or paste anything by hand. When the program is running, you select your electricity, water or gas meter. All very easy. All data is stored on the device itself, never in a cloud.

While the program is running, you see these new buttons in the Tasmota main menu:

⚙️ SMLAll program settings. With a PV battery emulator the button is called ⚙️ SML /🔋.
☁️ MarstekOnly in the CT002 emulator programs: register the CT in your Marstek account.
💻 TinyCOpens the TinyC Console: load, start and stop programs.

The charts have their own page. You open it with the 📈 link below the values on the main page. Or you switch on the option Main Charts, and they appear directly on the main page, like before with the scripts.

Install

  1. In Tasmota open Tools → TinyC Console.
  2. In the Repository box, choose SmartMeter/PV/Emulator (ottelo) in the upper list. On my images it is already selected.
  3. Choose the program in the list below, leave Slot 0 and press Download & Load.
  4. In the slot row, switch on A (start automatically after a reboot, turns green). If the program is not running yet, start it with ▶.

If you want to change a program yourself: the source code (.tc) is in the tinyc folder. You can compile it in the TinyC IDE, or all programs at once with bytecode/build.html.

The emulator programs only work in slot 0. Tasmota sends their web addresses to slot 0 only.

Meter, pins, language and most other settings are kept in a shared settings file. When you change to another program, they are still there.

Installation

  1. In Tasmota Werkzeuge → TinyC Console öffnen.
  2. Im Kasten Repository in der oberen Liste SmartMeter/PV/Emulator (ottelo) auswählen. Bei meinen Images ist das schon ausgewählt.
  3. In der Liste darunter das Programm auswählen, Slot 0 stehen lassen und Download & Load drücken.
  4. In der Zeile des Slots A einschalten (nach einem Neustart automatisch starten, wird grün). Läuft das Programm noch nicht, mit ▶ starten.

Wenn du ein Programm selbst ändern willst: Der Quellcode (.tc) liegt im Ordner tinyc. Kompilieren kannst du ihn in der TinyC-IDE oder alle Programme auf einmal mit bytecode/build.html.

Die Emulator-Programme funktionieren nur in Slot 0. Tasmota leitet ihre Webadressen nur an Slot 0 weiter.

Zähler, Pins, Sprache und die meisten anderen Einstellungen stehen in einer gemeinsamen Einstellungsdatei. Wechselst du das Programm, sind sie noch da.

Power savingEnergiesparmodus

Normally Tasmota lets the chip and the Wi-Fi rest for a moment between its tasks (Sleep 50). That saves a little power, but the device answers more slowly. With a weak Wi-Fi signal, a page or a reply can take several seconds.

OFF (default)Sleep 50. Uses less power.
ONSleep 0. The device never rests. Web page, charts and the answers to the battery come much faster.

What it made on an ESP32-C3 with weak Wi-Fi (−87 dBm), 25 page loads each:

Sleep 50Sleep 0
typical0.4 s0.14 s
slowest3.3 s0.28 s
slower than 1 second6 of 25none

The price: the device uses about 0.25 W more, around 2 kWh a year. That is well under one euro.

Which one for you

You use a battery emulatorON. The battery asks every second. A late answer makes the regulation worse.
Your Wi-Fi is weakON. Below about −80 dBm the power saving makes everything very slow.
You only read the meterOFF is fine. A few seconds of delay do not matter here.

Better Wi-Fi helps more than this switch. A repeater or access point near the meter makes the device faster and lets it save power.

Switching it off again sets Sleep 50, Tasmota's default. If you used a different value, set it again with the Sleep command. The box only acts when you change it here. A Sleep value set in the console is not touched at start-up.

Normalerweise lässt Tasmota den Chip und das WLAN zwischen seinen Aufgaben kurz ruhen (Sleep 50). Das spart etwas Strom, aber das Gerät antwortet langsamer. Bei schwachem WLAN kann eine Seite oder eine Antwort mehrere Sekunden dauern.

AUS (Standard)Sleep 50. Braucht weniger Strom.
EINSleep 0. Das Gerät ruht nie. Webseite, Diagramme und die Antworten an den Akku kommen deutlich schneller.

So sah das an einem ESP32-C3 mit schwachem WLAN aus (−87 dBm), je 25 Seitenaufrufe:

Sleep 50Sleep 0
typisch0,4 s0,14 s
am langsamsten3,3 s0,28 s
langsamer als 1 Sekunde6 von 25keiner

Der Preis: Das Gerät braucht etwa 0,25 W mehr, rund 2 kWh im Jahr. Das ist deutlich unter einem Euro.

Was passt für dich

Du nutzt einen Akku-EmulatorEIN. Der Akku fragt jede Sekunde. Eine späte Antwort verschlechtert die Regelung.
Dein WLAN ist schwachEIN. Unter etwa −80 dBm macht der Sparmodus alles sehr langsam.
Du liest nur den Zähler ausAUS reicht. Ein paar Sekunden Verzögerung stören hier nicht.

Besseres WLAN hilft mehr als dieser Schalter. Ein Repeater oder Access Point in der Nähe des Zählers macht das Gerät schneller und lässt es trotzdem Strom sparen.

Schaltest du ihn wieder aus, wird Sleep 50 gesetzt, der Tasmota-Standard. Hattest du einen anderen Wert, setze ihn mit dem Befehl Sleep neu. Das Häkchen wirkt nur, wenn du es hier änderst. Ein in der Konsole gesetzter Sleep-Wert wird beim Start nicht verändert.

MeterZähler

Descriptor

The descriptor is a small text file that tells Tasmota how to read your meter: speed, protocol and which value is which. It is stored on the device as /sml_meter.def. You normally just pick your meter from the list.

Meter activeSwitches the meter reading on or off. Off means no values at all.
3 phasesOff by default. Only switch it on if your meter really sends the power of each phase and the three phases are in the descriptor. Then the main page shows an L1 / L2 / L3 row, and the emulators pass on the real phase values instead of putting everything on L1. If the values do not fit, the program switches it off again and tells you.
MeterList of ready-made descriptors for many meters. Choose yours, and the file is downloaded and the reading restarts. Keiner/Selbstdefinierter Zähler (none / own meter) downloads nothing and keeps your current file, for a descriptor you wrote yourself. RX, TX and the filter are still filled in where the file contains the placeholders %0rxpin%, %0txpin% and %0smlf%.
DescriptorThe link opens the file in the editor, if you want to change something. Your meter is not in the list? Start with a similar one.

The first three values always have the same meaning, and everything else relies on that: 1 power [W], 2 energy bought [kWh], 3 energy fed in [kWh].

Der Descriptor ist eine kleine Textdatei. Sie sagt Tasmota, wie dein Zähler gelesen wird: Geschwindigkeit, Protokoll und welcher Wert welcher ist. Sie liegt auf dem Gerät als /sml_meter.def. Normalerweise wählst du deinen Zähler einfach aus der Liste.

Zähler aktivSchaltet das Auslesen ein oder aus. Aus heißt: gar keine Werte.
3 PhasenStandardmäßig aus. Nur einschalten, wenn dein Zähler die Leistung jeder Phase wirklich sendet und die drei Phasen im Descriptor stehen. Dann zeigt die Hauptseite eine Zeile L1 / L2 / L3, und die Emulatoren geben die echten Phasenwerte weiter, statt alles auf L1 zu legen. Passen die Werte nicht zusammen, schaltet das Programm die Option wieder aus und sagt dir Bescheid.
ZählerListe mit fertigen Descriptoren für viele Zähler. Wählst du deinen aus, wird die Datei heruntergeladen und das Auslesen neu gestartet. Keiner/Selbstdefinierter Zähler lädt nichts herunter und behält deine jetzige Datei, für einen selbst geschriebenen Descriptor. RX, TX und Filter werden trotzdem eingetragen, wo in der Datei die Platzhalter %0rxpin%, %0txpin% und %0smlf% stehen.
DescriptorDer Link öffnet die Datei im Editor, falls du etwas ändern willst. Dein Zähler fehlt in der Liste? Fang mit einem ähnlichen an.

Die ersten drei Werte haben immer dieselbe Bedeutung, darauf baut alles auf: 1 Leistung [W], 2 Bezug [kWh], 3 Einspeisung [kWh].

Pins

RX is the pin where the data wire of the reading head is connected. TX is only needed for meters that have to be woken up or asked for their data.

RX 3 · TX 1Hichi, Stromleser, LesekopfV32, Wattwächter
RX 5 · TX 4bitShake

The list only shows pins that are still free in Tasmota. A pin you already used in the module settings does not appear.

After a pin change the reading restarts by itself. You do not need to reboot.

RX ist der Pin, an dem die Datenleitung des Lesekopfs hängt. TX braucht man nur bei Zählern, die erst geweckt oder nach ihren Daten gefragt werden müssen.

RX 3 · TX 1Hichi, Stromleser, LesekopfV32, Wattwächter
RX 5 · TX 4bitShake

Die Liste zeigt nur Pins, die in Tasmota noch frei sind. Ein Pin, den du schon in der Modulkonfiguration belegt hast, taucht nicht auf.

Nach einer Änderung startet das Auslesen von selbst neu. Einen Neustart des Geräts brauchst du nicht.

Import meterBezugszähler

Off by default. This is for meters that only count the energy you buy, not the energy you feed in. You can still tell when you feed in: the power shown is negative then.

Switched on, the program adds up the negative power itself and uses that as your feed-in meter reading. Main page, charts, /pwr, Modbus and the emulators then show this value as feed-in. To see the feed-in rows and charts, switch on PV as well.

  • The calculated reading starts at 0. It only counts while the device is running and gets values from the meter.
  • It is about as exact as the power value. Good for daily and monthly totals, but not a calibrated meter.
  • When you switch the option on or off, today's, this week's, this month's and this year's feed-in start from zero again. Bars already drawn keep their values.
  • The reading is saved once a day at midnight and survives a program change. To take over the value from the old Scripter script (sml3): stop the program, enter the value as @exp_virt= in the settings file and start again.

This replaces the old script 3_SML_Chart_PV_Bezugszaehler.tas. If your meter does count the feed-in (value 3), leave this off.

Standardmäßig aus. Das ist für Zähler, die nur den Strom zählen, den du kaufst, nicht den, den du einspeist. Dass du einspeist, sieht man trotzdem: Die Leistung ist dann negativ.

Eingeschaltet zählt das Programm die negative Leistung selbst zusammen und nimmt das als deinen Einspeise-Zählerstand. Hauptseite, Diagramme, /pwr, Modbus und die Emulatoren zeigen dann diesen Wert als Einspeisung. Damit du die Einspeise-Zeilen und -Diagramme siehst, schalte zusätzlich PV ein.

  • Der berechnete Zählerstand beginnt bei 0. Er zählt nur, solange das Gerät läuft und Werte vom Zähler bekommt.
  • Er ist ungefähr so genau wie der Leistungswert. Gut für Tages- und Monatssummen, aber kein geeichter Zähler.
  • Schaltest du die Option ein oder aus, beginnen die Einspeisung von heute, dieser Woche, diesem Monat und diesem Jahr wieder bei null. Schon gezeichnete Balken bleiben.
  • Der Zählerstand wird einmal am Tag um Mitternacht gespeichert und bleibt bei einem Programmwechsel erhalten. Den Wert aus dem alten Scripter-Script (sml3) übernehmen: Programm stoppen, den Wert als @exp_virt= in die Einstellungsdatei eintragen, wieder starten.

Das ersetzt das alte Script 3_SML_Chart_PV_Bezugszaehler.tas. Zählt dein Zähler die Einspeisung selbst (Wert 3), lass die Option aus.

Gas and water metersGas- und Wasserzähler

Only in SML Simple and SML Chart. Instead of the electricity meter you can read a gas or water meter that gives pulses (for example with a reed contact). In the meter list under Allgemein you find the Gaszähler (0.01 m³ per pulse) and the Wasserzähler (1 litre per pulse). If your meter is different, change @100 or @1000 in the descriptor. That number is the number of pulses per m³.

The program sees the line ;kind=gas or ;kind=water in the descriptor and switches over by itself:

  • Main page: flow (gas in m³/h, water in l/min), the meter reading, and day, week, month and year, all in m³.
  • Charts: the flow in the line charts, the consumption in m³ in the bar charts.
  • Hidden: feed-in, 3 phases, import meter, PV switch and power2.

The flow is calculated from the change of the meter reading. If no new pulse comes, it goes down slowly.

Set the meter reading once in the Tasmota console, in pulses. Example for gas: Sensor53 c1 123456 means 1234.56 m³. Your own descriptor works too: value 2 must be the reading in m³, and the line ;kind= must be in the file. After changing the descriptor by hand, press Save once.

If you used the device for electricity before, the totals still start from the old kWh reading. Press Data → 🔢 Reset and 📊 Reset once.

Nur in SML Simple und SML Chart. Statt des Stromzählers kannst du einen Gas- oder Wasserzähler auslesen, der Impulse abgibt (zum Beispiel über einen Reedkontakt). In der Zählerliste unter Allgemein findest du den Gaszähler (0,01 m³ pro Impuls) und den Wasserzähler (1 Liter pro Impuls). Ist dein Zähler anders, ändere @100 bzw. @1000 im Descriptor. Diese Zahl ist die Anzahl der Impulse pro m³.

Das Programm erkennt die Zeile ;kind=gas oder ;kind=water im Descriptor und stellt selbst um:

  • Hauptseite: Durchfluss (Gas in m³/h, Wasser in l/min), Zählerstand sowie Tag, Woche, Monat und Jahr, alles in m³.
  • Diagramme: der Durchfluss in den Liniendiagrammen, der Verbrauch in m³ in den Balken.
  • Ausgeblendet: Einspeisung, 3 Phasen, Bezugszähler, PV-Schalter und power2.

Der Durchfluss wird aus der Änderung des Zählerstands berechnet. Kommt kein neuer Impuls, sinkt er langsam.

Den Zählerstand setzt du einmal in der Tasmota-Konsole, in Impulsen. Beispiel für Gas: Sensor53 c1 123456 bedeutet 1234,56 m³. Ein eigener Descriptor geht auch: Wert 2 muss der Zählerstand in m³ sein, und die Zeile ;kind= muss in der Datei stehen. Nach einer Änderung am Descriptor von Hand einmal Speichern drücken.

Hast du das Gerät vorher für Strom benutzt, zählen die Summen noch vom alten kWh-Stand. Drücke einmal unter Daten 🔢 Reset und 📊 Reset.

Filter

Smooths out single wrong values from the meter. Such spikes make the charts hard to read and confuse a battery.

Leave it on unless you need the raw values. It makes the values a little slower, which only matters for battery regulation.

Glättet einzelne falsche Werte vom Zähler weg. Solche Ausreißer machen die Diagramme unleserlich und bringen einen Akku durcheinander.

Lass ihn an, außer du brauchst die Rohwerte. Er macht die Werte etwas langsamer, was nur bei der Akkuregelung eine Rolle spielt.

SML displaySML Anzeige

Tasmota itself can also show the meter values on the main page, with the meter name in front of each value. The program already shows the important values, in your language and without that name.

OFF (default)Only the program's rows. Tidier.
ONTasmota's rows as well. Useful while you set up a descriptor, because you see every value, not only the first three.

MQTT (SENSOR) always contains all meter values, no matter what you choose here. Home Assistant is not affected.

Tasmota kann die Zählerwerte auch selbst auf der Hauptseite anzeigen, mit dem Zählernamen vor jedem Wert. Das Programm zeigt die wichtigen Werte schon an, in deiner Sprache und ohne diesen Namen.

AUS (Standard)Nur die Zeilen des Programms. Übersichtlicher.
EINZusätzlich die Zeilen von Tasmota. Praktisch beim Einrichten eines Descriptors, weil du jeden Wert siehst, nicht nur die ersten drei.

MQTT (SENSOR) enthält immer alle Zählerwerte, egal was du hier einstellst. Home Assistant merkt davon nichts.

PV

Only in the chart programs. OFF shows only what you buy. ON also shows what you feed in: the feed-in meter reading, rows for day, week, month and year, a chart of the daily feed-in, and both directions in the week and month charts.

Switch it on if your meter counts the feed-in (it has 1.8.0 and 2.8.0). If it does not, but the power goes negative when you feed in, also switch on Import meter. Without solar panels the extra charts just stay at zero.

Nur in den Diagramm-Programmen. AUS zeigt nur, was du kaufst. EIN zeigt auch, was du einspeist: den Einspeise-Zählerstand, Zeilen für Tag, Woche, Monat und Jahr, ein Diagramm der täglichen Einspeisung und beide Richtungen in den Wochen- und Monatsdiagrammen.

Schalte es ein, wenn dein Zähler die Einspeisung zählt (er hat 1.8.0 und 2.8.0). Tut er das nicht, wird die Leistung beim Einspeisen aber negativ, schalte zusätzlich Bezugszähler ein. Ohne Solaranlage bleiben die zusätzlichen Diagramme einfach auf null.

ChartsDiagramme

Short-termThe time span of the first chart: 15 min, 30 min, 1 h, 2 h or 4 h (default). The shorter the span, the more detail: at 15 minutes there is a point every 5 seconds, at 4 hours one per minute.
Main ChartsOff: the charts are on their own page, opened with the 📈 link. On: they are drawn on the Tasmota main page below the values, and the link disappears. The separate page still works at /tc_ui?p=2.

If you choose a different time span and save, the short-term chart starts empty. The 24 h chart and the bar charts are not affected.

Week chart. Shows calendar weeks 1 to 53. A week starts on Monday. The current week has a red border. The weeks still to come this year are drawn pale: they still show last year's values until it is their turn again. So the chart always covers the last twelve months.

The ↻ Auto button above the charts reloads the page every 10 seconds. Without it the charts stay as they were when you opened the page. Your browser remembers this setting. While you are typing in a field, the page is not reloaded.

KurzzeitDie Zeitspanne des ersten Diagramms: 15 min, 30 min, 1 h, 2 h oder 4 h (Standard). Je kürzer die Spanne, desto genauer: bei 15 Minuten gibt es alle 5 Sekunden einen Punkt, bei 4 Stunden einen pro Minute.
Charts HauptseiteAus: Die Diagramme liegen auf einer eigenen Seite, die du über den Link 📈 öffnest. Ein: Sie werden auf der Tasmota-Hauptseite unter den Werten gezeichnet, und der Link fällt weg. Die eigene Seite geht trotzdem weiter unter /tc_ui?p=2.

Wählst du eine andere Zeitspanne und speicherst, beginnt das Kurzzeit-Diagramm leer. Das 24-h-Diagramm und die Balkendiagramme bleiben, wie sie sind.

Wochendiagramm. Zeigt die Kalenderwochen 1 bis 53. Eine Woche beginnt am Montag. Die aktuelle Woche ist rot umrandet. Die Wochen, die dieses Jahr noch kommen, sind blass: Sie zeigen noch die Werte vom letzten Jahr, bis sie wieder dran sind. So zeigt das Diagramm immer die letzten zwölf Monate.

Der Knopf ↻ Auto über den Diagrammen lädt die Seite alle 10 Sekunden neu. Ohne ihn bleiben die Diagramme so, wie sie beim Öffnen der Seite waren. Dein Browser merkt sich die Einstellung. Während du in einem Feld tippst, wird nicht neu geladen.

Chart dataDiagrammdaten

🔢 ResetStarts the values for today, this week, month and year again from the current meter reading. Do this once after installing, and whenever the values look wrong. If you see the whole meter reading instead of today's consumption, this is what you need. The charts keep their history.
📈 ResetEmpties the short-term chart and the 24 h chart. The values and the bar charts stay.
📊 ResetDeletes the bars for days, weeks and months. The counting goes on.

All three buttons ask before they delete anything.

The 💾 CSV button at the bottom of the settings page saves the chart data as a table: /sml_chart.csv, and with feed-in also /sml_chart_pv.csv. You can download the files in Tasmota's file manager and open them in a spreadsheet. This also works when the meter delivers no values.

The program itself keeps its data in its own .pvs file. For a backup, copy this one file away. To restore it, copy it back and restart the program. The file /sml_chart.bin is only used once, to take over data from an older version.

The charts need the correct time. Until the device has fetched the time from the internet, nothing is recorded.

🔢 ResetLässt die Werte für heute, diese Woche, diesen Monat und dieses Jahr wieder beim aktuellen Zählerstand beginnen. Mach das einmal nach der Installation und immer dann, wenn die Werte falsch aussehen. Siehst du den ganzen Zählerstand statt des heutigen Verbrauchs, ist das die Lösung. Die Diagramme behalten ihren Verlauf.
📈 ResetLeert das Kurzzeit- und das 24-h-Diagramm. Die Werte und die Balkendiagramme bleiben.
📊 ResetLöscht die Balken für Tage, Wochen und Monate. Gezählt wird weiter.

Alle drei Knöpfe fragen nach, bevor sie etwas löschen.

Der Knopf 💾 CSV ganz unten auf der Einstellungsseite speichert die Diagrammdaten als Tabelle: /sml_chart.csv, mit Einspeisung zusätzlich /sml_chart_pv.csv. Herunterladen kannst du sie im Dateimanager von Tasmota und in einer Tabellenkalkulation öffnen. Das geht auch, wenn der Zähler gerade keine Werte liefert.

Das Programm selbst speichert seine Daten in seiner eigenen .pvs-Datei. Für eine Sicherung kopierst du diese eine Datei weg. Zum Zurückholen kopierst du sie zurück und startest das Programm neu. Die Datei /sml_chart.bin wird nur einmal gelesen, um Daten aus einer älteren Version zu übernehmen.

Die Diagramme brauchen die richtige Uhrzeit. Solange das Gerät die Zeit noch nicht aus dem Internet geholt hat, wird nichts aufgezeichnet.

TelemetryTelemetrie

Send power2 (MQTT) (with an emulator: Send power2 + cpwr (MQTT)) is off by default. Switched on, the program sends a strongly smoothed power value every 5 seconds over MQTT. With an emulator it also sends cpwr, the value the battery gets. The switch is only for MQTT. The web address /pwr always works. Below the switch you see the current values and links to /pwr and /pwr?v=.

MQTT

stat/<topic>/script/power2Smoothed power [W]. Reacts slowly on purpose.
stat/<topic>/script/cpwrOnly with an emulator: the value the battery gets, including the offset.

In MQTT Explorer or Home Assistant you find the values under stat → <topic> → script, for example stat/tasmota_31F8D4/script/power2. <topic> is the MQTT topic of your device (Tasmota: Configuration → MQTT → Topic).

HTTP /pwr

{"sml1":-440,"sml2":26714.950,"sml3":659.775,"sml4":-440,"sml5":0,"sml6":0,"power2":-217,"cpwr":-180}

Useful for a second battery or control system that asks for the values over the network, for example the dynamic power limiter of opendtu-onbattery. It always works and needs no password.

sml1 to sml6 are the meter values. Without 3 phases, sml4 is the total power and sml5/sml6 are 0. cpwr only appears with an emulator.

Why smoothed? A battery that follows every short spike starts to swing. sml1 is the raw value, power2 the calm one.

The MQTT messages only show up in the console from weblog 3 on, so the console stays readable. If sending fails, this is logged once. -2 means MQTT is switched off on the device.

power2 senden (MQTT) (mit Emulator: power2 + cpwr senden (MQTT)) ist standardmäßig aus. Eingeschaltet schickt das Programm alle 5 Sekunden einen stark geglätteten Leistungswert per MQTT. Mit Emulator schickt es zusätzlich cpwr, den Wert, den der Akku bekommt. Der Schalter gilt nur für MQTT. Die Webadresse /pwr funktioniert immer. Unter dem Schalter siehst du die aktuellen Werte und Links zu /pwr und /pwr?v=.

{"sml1":-440,"sml2":26714.950,"sml3":659.775,"sml4":-440,"sml5":0,"sml6":0,"power2":-217,"cpwr":-180}

Praktisch für einen zweiten Akku oder eine Steuerung, die die Werte übers Netzwerk abfragt, zum Beispiel den Dynamic Power Limiter von opendtu-onbattery. Das geht immer und ohne Passwort.

Warum geglättet? Ein Akku, der jeder kurzen Spitze folgt, fängt an zu schwingen. sml1 ist der Rohwert, power2 der ruhige.

Die MQTT-Nachrichten erscheinen in der Konsole erst ab weblog 3, damit die Konsole lesbar bleibt. Klappt das Senden nicht, steht das einmal im Log. -2 heißt, MQTT ist auf dem Gerät ausgeschaltet.

HTTP /pwr?v=

All programs. Gets single values as JSON, with the same names as in the old Scripter scripts (cm?cmnd=script?dval;dcon). It always works and needs no password.

http://<ip>/pwr?v=sml[1];yval;dcon
{"sml[1]":-3.000,"yval":2140.315,"dcon":[12.410,9.800, ...]}

Separate several names with ;. ?v=all gives you all values except the chart data. A name the program does not know gives null.

sml[n] / smlnMeter value number n. sml[3] is the feed-in reading (calculated with Import meter). Without 3 phases, sml4 is the total power and sml5/sml6 are 0.
smlShort for sml1;sml2;sml3;sml4;sml5;sml6
power2Smoothed power [W]
cpwrOnly with an emulator: the value the battery gets [W]
dval wval mval yvalOnly in chart programs, like everything below. Energy bought today, this week, month and year [kWh], as on the main page

Modbus-TCP

Off by default. Switched on, other devices can read the meter values over Modbus-TCP, for example an inverter or a home automation system.

Addressor written asValueUnit
040001PowerW
240003Energy boughtkWh
440005Energy fed inkWh

There are two ways of counting the same addresses. Some programs start at 0, others at 40001. If you get the error illegal data address, try the other column.

Settings for the client: function code 03 (Read Holding Registers), 2 registers per value, format 32-bit float, big-endian. To read all three values at once, read 6 registers starting at address 0.

Testing with Modbus Poll

Address 0 (or 40001 if PLC addresses (base 1) is ticked), Quantity 2 for one value or 6 for all three. Then select the two registers of one value and choose Format → 32-bit Float Big-Endian to see the real number.

Port 502 is the standard. Only change it if something else on the device already uses it. A change works within a second, without a reboot.

Standardmäßig aus. Eingeschaltet können andere Geräte die Zählerwerte über Modbus-TCP lesen, zum Beispiel ein Wechselrichter oder eine Hausautomation.

Adresseoder geschrieben alsWertEinheit
040001LeistungW
240003BezugkWh
440005EinspeisungkWh

Für dieselben Adressen gibt es zwei Zählweisen. Manche Programme beginnen bei 0, andere bei 40001. Bekommst du den Fehler illegal data address, probier die andere Spalte.

Einstellungen für die Gegenseite: Funktionscode 03 (Read Holding Registers), 2 Register pro Wert, Format 32-Bit-Float, Big-Endian. Alle drei Werte auf einmal: 6 Register ab Adresse 0 lesen.

Testen mit Modbus Poll

Adresse 0 (oder 40001, wenn PLC addresses (base 1) angehakt ist), Quantity 2 für einen Wert oder 6 für alle drei. Dann die zwei Register eines Werts markieren und Format → 32-Bit Float Big-Endian wählen, damit die richtige Zahl erscheint.

Port 502 ist der Standard. Ändere ihn nur, wenn ihn auf dem Gerät schon etwas anderes benutzt. Eine Änderung wirkt innerhalb einer Sekunde, ohne Neustart.

PV switchPV-Schalter

All programs, off by default. When you have solar power to spare, it switches on a second Tasmota device, for example a smart plug with a pool pump. When the surplus is gone, it switches the device off again. This is the same as option (Op1) of the old scripts. In the chart programs you find it under PV, as soon as Feed-in is switched on.

IPIP address of the other device.
On [W]Switches on when the power drops below this value. Negative means feed-in. Default −300: on from 300 W feed-in.
Off [W]Switches off when the power rises above this value. Default 100: off from 100 W bought. It can not be lower than On; Save corrects it if needed.

The switch uses the smoothed power (power2), so a passing cloud does not switch the device. A command is only sent when the state changes. The main page shows whether the device is on or off. If you untick the option or enter another IP, the old device is switched off first.

The Toggle button switches the other device by hand, for a quick test. It also works before you save. It does not show whether the device is on or off.

The other device

  • It runs Tasmota and can be reached from this device. Give it a fixed IP address (in your router).
  • It must not have a web password, otherwise it refuses the command.
  • The appliance is connected to relay 1.
  • Tip: set PowerOnState 0 on it. Then it stays off after a power cut until there is surplus again.

Alle Programme, standardmäßig aus. Hast du Solarstrom übrig, schaltet er ein zweites Tasmota-Gerät ein, zum Beispiel eine Steckdose mit Poolpumpe. Ist der Überschuss weg, schaltet er es wieder aus. Das ist dasselbe wie die Option (Op1) der alten Scripte. In den Diagramm-Programmen findest du ihn unter PV, sobald Einspeisung eingeschaltet ist.

IPIP-Adresse des anderen Geräts.
Ein [W]Schaltet ein, wenn die Leistung unter diesen Wert fällt. Negativ heißt Einspeisung. Standard −300: ein ab 300 W Einspeisung.
Aus [W]Schaltet aus, wenn die Leistung über diesen Wert steigt. Standard 100: aus ab 100 W Bezug. Der Wert kann nicht kleiner als Ein sein, Speichern korrigiert ihn sonst.

Der Schalter nutzt die geglättete Leistung (power2). Eine vorbeiziehende Wolke schaltet also nicht. Gesendet wird nur, wenn sich der Zustand ändert. Die Hauptseite zeigt, ob das Gerät ein- oder ausgeschaltet ist. Nimmst du das Häkchen weg oder trägst eine andere IP ein, wird das alte Gerät vorher ausgeschaltet.

Der Knopf Umschalten schaltet das andere Gerät von Hand um, für einen schnellen Test. Das geht auch schon vor dem Speichern. Ob das Gerät gerade ein oder aus ist, zeigt der Knopf nicht.

Das andere Gerät

  • Es läuft mit Tasmota und ist von diesem Gerät aus erreichbar. Gib ihm eine feste IP-Adresse (im Router).
  • Es darf kein Web-Passwort haben, sonst lehnt es den Befehl ab.
  • Der Verbraucher hängt an Relais 1.
  • Tipp: Stelle dort PowerOnState 0 ein. Dann bleibt es nach einem Stromausfall aus, bis wieder Überschuss da ist.

Settings fileEinstellungsdatei

Each program keeps its data in its own file. So that you do not have to set everything up again after changing the program, the shared settings are also kept in /tc_options.cfg. All programs use this file.

# tc_options - shared by all programs
@ui_de=1
@sml_meter_sel=89
@sml_rx_pin=3
@sml_tx_pin=1
@sml_ph3=1
@es_mode=2
@sml_da=3
@chart_short=240
@imp_day=26714.950
@exp_day=659.775

Each line is @name=value. A program reads the lines it knows and keeps all others as they are. If you run sml_simple for a while, the emulator settings are still there when you change back.

ui_*Language, power saving.
sml_*Meter, RX/TX pin, filter, phases, display.
es_* / ct_* / mb_*Emulators and Modbus.
chart_*chart_short is the time span of the short-term chart in minutes (15, 30, 60, 120, 240). chart_onmain puts the charts on the Tasmota main page.
imp_* / exp_*The meter readings at the start of the day, week, month and year, in kWh. The program uses them to work out your consumption. sml_da belongs to them.
sml_bezug / exp_virtThe Import meter option and its calculated feed-in reading in kWh.
sw_*The PV switch: on/off, On [W], Off [W], IP.

Changing it by hand

Download the file, change it, upload it, then restart the program. Keep this order. A running program would otherwise write its own values back over yours.

Usually you would only correct the start readings. Set imp_day to the meter reading at midnight, and today's consumption is right again.

Do not delete the file to reset something. It is written again from the data of the running program, and after a program change that can be zeros.

The file is only written when something has changed: when you save a setting, and once at midnight. That is about once a day, which is gentle on the flash memory.

Jedes Programm speichert seine Daten in einer eigenen Datei. Damit du nach einem Programmwechsel nicht alles neu einstellen musst, stehen die gemeinsamen Einstellungen zusätzlich in /tc_options.cfg. Diese Datei nutzen alle Programme.

@sml_meter_sel=89
@sml_rx_pin=3
@sml_tx_pin=1
@sml_ph3=1
@es_mode=2
@sml_da=3

Jede Zeile hat die Form @name=wert. Ein Programm liest die Zeilen, die es kennt, und lässt alle anderen stehen. Läuft eine Weile sml_simple, sind die Emulator-Einstellungen beim Zurückwechseln noch da.

ui_*Sprache, Energiesparmodus.
sml_*Zähler, RX-/TX-Pin, Filter, Phasen, Anzeige.
es_* / ct_* / mb_*Emulatoren und Modbus.
chart_*chart_short ist die Zeitspanne des Kurzzeit-Diagramms in Minuten (15, 30, 60, 120, 240). chart_onmain legt die Diagramme auf die Tasmota-Hauptseite.
imp_* / exp_*Die Zählerstände am Anfang von Tag, Woche, Monat und Jahr, in kWh. Daraus rechnet das Programm deinen Verbrauch aus. sml_da gehört dazu.

Von Hand ändern

Datei herunterladen, ändern, hochladen, dann das Programm neu starten. Halte diese Reihenfolge ein. Ein laufendes Programm würde sonst seine eigenen Werte über deine schreiben.

Meistens korrigiert man nur die Anfangsstände. Setzt du imp_day auf den Zählerstand um Mitternacht, stimmt der heutige Verbrauch wieder.

Lösche die Datei nicht, um etwas zurückzusetzen. Sie wird aus den Daten des laufenden Programms neu geschrieben, und das können nach einem Programmwechsel Nullen sein.

Die Datei wird nur geschrieben, wenn sich etwas geändert hat: wenn du eine Einstellung speicherst, und einmal um Mitternacht. Also etwa einmal am Tag, das schont den Flash-Speicher.

TroubleshootingFehlersuche

All values 0Check Meter active first, then the pins, then the descriptor. Switch on SML display: if Tasmota shows no values either, the meter is not being read at all.
Power has the wrong signBought and fed-in are swapped in the descriptor. Feed-in must be negative.
Values jump aroundSwitch on the filter. If it stays restless, the reading head does not sit straight on the meter's light window.
Charts stay emptyThe device has no time from the internet yet, or the start readings were never set. See chart data.
Settings gone after a rebootSettings are saved when you press Save and when the program stops. A power cut right after a change can lose that change.
Modbus does not answerCheck the port, and whether the Wi-Fi was already connected when the program started.
Alle Werte 0Zuerst Zähler aktiv prüfen, dann die Pins, dann den Descriptor. Schalte SML Anzeige ein: Zeigt auch Tasmota keine Werte, wird der Zähler gar nicht gelesen.
Leistung hat das falsche VorzeichenBezug und Einspeisung sind im Descriptor vertauscht. Einspeisung muss negativ sein.
Werte springenFilter einschalten. Bleibt es unruhig, sitzt der Lesekopf nicht gerade auf dem Lichtfenster des Zählers.
Diagramme bleiben leerDas Gerät hat noch keine Uhrzeit aus dem Internet, oder die Anfangsstände wurden nie gesetzt. Siehe Diagrammdaten.
Einstellungen nach Neustart wegGespeichert wird beim Drücken auf Speichern und wenn das Programm stoppt. Ein Stromausfall direkt nach einer Änderung kann diese Änderung kosten.
